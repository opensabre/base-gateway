# 边缘网关

## 模块介绍

边缘网关负责将外部请求按路由规则转发到下游服务，并在转发前执行统一的安全与网关处理。

## 功能

- 基于路由配置的请求转发；
- URL/HTTP 方法维度的权限判定；
- 网关过滤器和异常处理；
- 在线用户记录与 API 文档聚合（以当前配置为准）。

## 使用

路由通过受控的管理/配置发布流程变更。开发人员新增服务时，需要确认服务注册、路由、资源权限和 OpenAPI 暴露是否完整，不能只添加一条转发规则。

## 流程

```text
客户端请求 → 路由匹配 → 令牌/资源权限校验 → 网关过滤器 → 下游服务 → 响应处理
```

## 规划

- 把路由发布、版本、回滚与运行时校验形成统一 Runbook；
- 补充权限决策、限流、熔断和下游失败的可观测性；
- 建立新增服务接入网关的自动检查清单。
